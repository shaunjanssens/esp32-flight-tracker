Flight Tracker

Live aircraft around you on a 480×480 round touch screen. Range rings, cardinal marks, trails, and tap an aircraft for its route. No map tiles.

This browser can't talk to serial devices. Use Chrome or Edge on a desktop — Safari and Firefox have no Web Serial support. This page has to be served over HTTPS to access the serial port.

Plug the board in over USB first.

Hardware

Board
Waveshare ESP32-S3-Touch-LCD-2.1
Display
2.1″ round IPS, 480×480, ST7701 over RGB
Memory
8 MB octal PSRAM, 16 MB flash

Nothing else is needed — no receiver, no antenna. Aircraft data comes from community ADS-B feeds over your Wi-Fi.

If the board won't connect

This board has no USB-to-serial chip, so it can be fussy about entering flash mode:

  • Hold BOOT, plug the cable in, then release BOOT.
  • After flashing, unplug and replug the cable. The reset that esptool performs cannot clear this chip's download-mode latch, so it will sit at “waiting for download” until it is power-cycled.

First run

  • The device starts its own Wi-Fi network called FlightTracker-XXXX.
  • Join it and the setup page opens by itself. Enter your Wi-Fi, then drop a pin on the map for your home position.
  • It restarts onto your network. Long-press the screen for range and the device address; everything else lives at http://flighttracker.local/.
  • Later updates go over Wi-Fi — the cable is only needed this once.
Aircraft data from adsb.fi and adsb.lol, routes from adsbdb.com. Data is ODbL. Source on GitHub.
